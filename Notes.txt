🎯 Purpose

HalfYourBook is a platform for unpublished authors, hobby writers, and works-in-progress.

Authors share generous previews, partial manuscripts, unfinished stories, or full texts to be read.

No obligation to sell.

If authors choose to sell, they link out directly (no payments handled by the app).

Focus is connection, feedback, encouragement, and discovery, not algorithms or pressure.

🔌 Ports & Processes (IMPORTANT DISCOVERY)

HalfYourBook backend used to run on 3001, but now standardised on 3004.

Earlier “Request failed”, login, and register errors were caused by:

frontend proxy still pointing at 3001

or an old backend process still running on 3001

Fix: align backend PORT=3004 and Vite proxy.

💾 Database Backups (CRITICAL)
Local backup location
/c/Users/User/backups/halfyourbook/

Naming

Local: LOCAL_halfyourbook_YYYY-MM-DD_HH-MM.sql.gz

Server: SERVER_halfyourbook_YYYY-MM-DD_HHMM.sql.gz

Latest confirmed server backup (pulled local)
SERVER_halfyourbook_2026-01-31_1806.sql.gz

Local backup command
docker exec halfyourbook_db pg_dump -U postgres -d halfyourbook --no-owner --no-acl \
  | gzip > /c/Users/User/backups/halfyourbook/LOCAL_halfyourbook_$(date +"%Y-%m-%d_%H-%M").sql.gz

Server backup command
docker exec halfyourbook_db pg_dump -U postgres --no-owner --no-acl halfyourbook \
  | gzip > /root/backups/halfyourbook/SERVER_halfyourbook_$(date +%Y-%m-%d_%H%M).sql.gz

🔄 Restore Lessons (IMPORTANT)

Never restore a full pg_dump into a DB with existing schema

Either:

DROP SCHEMA public CASCADE; then restore

or restore into a new database

Restore errors like “relation already exists” are expected otherwise

After restore:

npx prisma generate
npm run dev
